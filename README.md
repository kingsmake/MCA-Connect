# MCA Connect – Digital Outreach Platform

This project is developed to create awareness about the MCA program among students.

## Features:
- Interactive UI with animations
- Career guidance section
- Placement information
- Quiz system for student evaluation
- Admin dashboard
- Student registration system

## Technologies Used:
- Frontend: React, Tailwind CSS
- Backend: Node.js, Express
- Database: MongoDB

## Purpose:
To digitally promote MCA and provide students with complete information and guidance.
